# Harness Engineer for ChatGPT — candidate 1.0.1

This edition is a project-instruction and knowledge pack, not a native code agent,
API application, plugin or one-click ZIP importer. It preserves the same three
working modes and seven-job method without assuming terminal tools or local files.

Manual setup:
1. Extract locally and review these files; never upload secrets or private material
   unless your account/workspace policies permit it.
2. Create a private project if that feature is available to your account.
3. Copy PROJECT-INSTRUCTIONS.md into project instructions.
4. Add KNOWLEDGE.md as a project source/knowledge file. Start a new project chat.
5. Use a prompt from START-HERE.md and run its manual acceptance checks.

No project feature available? Paste the instructions into a fresh chat and attach
KNOWLEDGE.md, subject to your account limits. Do not assume persistence across chats.
Do not upload the ZIP expecting automatic agent/skill installation.

No connectors, tools, API keys or local directory access are granted by this pack.
It does not enable independent subagents. Existing host features remain separate
and must be explicitly configured and authorized. This does not claim that all
ChatGPT or Claude products lack agent/skill capabilities.

To update, replace only your copied project instructions and knowledge file after
review. To uninstall, remove those project materials; no local agent is installed.
Client/subscription/model charges and feature access depend on your account.

Validation covers ZIP/content structure and review, not a live test in your chat
account. No paid calls, publication, installation or account changes occurred.
